# Stuff to Investigate

An internal map of scientific questions, sub-questions, and findings, including
projects we have considered but are not actively pursuing.

## Status

Version 1: a single-page, browser-only editable hierarchical list (`index.html`).
Data is stored in the browser's local storage with JSON export/import.

Next: shared backend with login and admin-approved accounts.

## Running locally

Open `index.html` directly in a browser, or serve the folder:

    python3 -m http.server 8765

then visit http://localhost:8765.
